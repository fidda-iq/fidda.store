# FIDDA — Public Store

هذه النسخة هي النسخة العامة فقط من متجر فِضّة.
تم استبعاد لوحة الإدارة وملفات SQL الخاصة بالإعداد.

## النشر على GitHub Pages
ارفع محتويات هذا المجلد إلى مستودع GitHub مخصص للموقع، ثم:
Settings → Pages → Deploy from a branch → main → /(root) → Save

بعد النشر يكون الموقع متاحًا للزوار. لوحة الإدارة ليست ضمن ملفات الموقع العام.
