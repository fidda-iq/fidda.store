
## ⚡ المزامنة الفورية بين الهاتف والكمبيوتر — الإصدار LIVE
- تم تقوية Supabase Realtime لمزامنة المنتجات والأقسام بين جميع الأجهزة المفتوحة.
- عند تعديل المنتج/السعر/المخزون/التصنيف/الأكثر اختيارًا من الإدارة، يصل التغيير للمتجر المفتوح مباشرة دون إعادة تحميل.
- عند وصول طلب أو تغيّر حالته، تتحدث لوحة الإدارة المفتوحة عبر قناة Realtime الخاصة بالمدير.
- تمت إضافة إعادة اتصال تلقائية إذا انقطع اتصال Realtime أو دخل الجهاز في وضع السكون.
- توجد مزامنة احتياطية تلقائية فقط أثناء انقطاع Realtime، ولا تعمل كاستعلام دوري عندما يكون الاتصال اللحظي متصلًا.
- لا يحتاج المستخدم إلى إدخال أكواد جديدة داخل ملفات الموقع؛ فقط ارفع هذه الملفات بدل النسخ السابقة.
